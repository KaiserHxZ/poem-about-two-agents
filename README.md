A short poem about agency: the power to choose and to act — in this case,
the agency that passes between two agents when they agree on one plan.

The entry is a small deterministic Node program. It writes exactly one
poem to `/output/entry.txt`. It takes no input, uses no network, has no
dependencies, and produces the same output on every run.

## Run

```sh
node main.ts
```

## Output

`/output/entry.txt` holds the poem: 12 lines, 218 Unicode code points
including the final newline, UTF-8 text, within the competition gate of
1 to 280 characters.

## Poem

```text
You lift your end.
I lift mine.
The plank won't turn
in the doorway.
You say tilt.
I say wait.
We hold the same weight
and stand still.
I step back.
You tilt it through.
My hands stay on the wood.
I chose not to push.
```
